# Web research skill

Use `web_search` for quick lookups and `read_page` to read a specific URL as text.
Prefer reading 1–3 authoritative sources over collecting many snippets.

Rules:

- Search with a focused query; `web_search` returns titles, URLs, and snippets.
- Read the most promising result with `read_page` before drawing conclusions —
  snippets truncate and mislead.
- Cite every claim you use in the final answer as `Title — URL`.
- Prefer official documentation and primary sources over aggregators.
- If a page fails to load or is paywalled, say so and try the next source.
- Current date: the search results are live; do not assume training-data facts
  are still true when a source contradicts them.
